# VEV

**European infrastructure software for the composable enterprise.**

VEV builds open, modular, long-lived software that helps organisations see their
own systems clearly — and change them without fear.

Engineering-first. Open by default. Built to last.

---

### The problem we work on

Complexity is growing faster than organisations can understand it. Cloud, SaaS,
fragmented tooling — and now AI — reshape enterprise landscapes faster than any
team can keep track of, exactly as the cost of not understanding them rises:
governance, security, regulation, and the growing need for European digital
sovereignty.

The result is familiar: capable organisations that can no longer answer basic
questions about their own systems. What do we actually run? What depends on
what? What is reaching end-of-life? Where does our data go?

We exist to close that gap — with durable software, not another dashboard.

### What we build

**VEV Atlas** — a living map of your architecture, always current.
See your entire landscape: applications, integrations, ownership, criticality and
end-of-life. Turn scattered, out-of-date documentation into a map that stays
current, so you can plan change with evidence instead of guesswork.

**VEV Portic** — one open gateway for every AI model.
An open-source, self-hostable gateway and control plane. One stable API to any
provider or self-hosted model, with routing, cost control, policy, observability
and audit built in — so AI stays a governed, portable, replaceable part of your
systems, never an opaque dependency. Apache 2.0.

### How we build

- **Engineering first** — software before slideware; known by what runs.
- **Open by default** — open standards, open interfaces, data you can take with you.
- **Modular** — small, sharp products that stand alone and compound together.
- **Long-lived** — built for the decade; durability is the feature.
- **European** — sovereignty, privacy and independence as defaults, not add-ons.
